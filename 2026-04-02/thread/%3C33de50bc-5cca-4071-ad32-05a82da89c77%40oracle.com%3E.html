pynfs 0.5 Release and ACL Test Status

Summary

The NFS community announced the release of pynfs-0.5, a significant update to the Python-based NFS testing framework, marking progress in server-side validation capabilities. The release includes contributions from Bryan Schmersal, Chuck Lever, Scott Mayhew, and Tigran Mkrtchyan, focusing on slot management, secure connections, callback notifications, and delegation handling.

Key Technical Updates in pynfs-0.5

The release addresses several critical areas of NFS client and server interaction:

  • Slot Management Fixes: Bryan Schmersal contributed patches to refine how slots are reused. Specifically, the framework now "Actually reuse[s] the slot only when the sequence op gets an NFS4ERR_DELAY status," preventing unnecessary slot consumption when other operations trigger delays. Additionally, Tigran Mkrtchyan added logic to "mark slot free after compound op complete" in NFSv4.1 scenarios.
  • Enhanced Testing Capabilities: Scott Mayhew introduced support for CB_NOTIFY_LOCK callbacks and added tests for expired clients. He also enabled the server helper scripts to forcibly expire clients, a useful feature for testing state recovery. Tigran Mkrtchyan added a test for "read with delegation stateid after close," ensuring proper delegation handling.
  • Infrastructure Improvements: Bryan Schmersal allowed max_retries and delay_time arguments in compound operations and enabled NFSv3 clients to connect via secure ports. Chuck Lever added tests for unsupported fattr4 attributes, improving coverage of attribute negotiation.

This indicates that the ACL tests are not missing but are held back due to transient testing issues on the maintainer's side, with a commitment to integrate them once resolved.

Conclusion

The pynfs-0.5 release strengthens the NFS testing infrastructure, particularly around slot management and callback notifications. The discussion highlights the collaborative nature of the project, with maintainers actively addressing integration hurdles for pending features like ACL testing.
