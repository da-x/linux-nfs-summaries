NFS Client Fix: RENAME Attribute Staleness with Directory Delegations Resolved

Summary

This thread concerns a bug fix in the Linux NFS client addressing a regression in attribute handling during RENAME operations when directory delegations are active. The discussion bridges from last week, when Olga Kornievskaia submitted the patch, to this week, where it received review acknowledgment.

Background and Technical Context

The issue stems from an earlier optimization commit, 6f9bda2337f8 ("NFS: Fix directory delegation verifier checks"), which altered how the client handles directory delegation verifiers to reduce wire traffic. While beneficial for performance, this change inadvertently caused a regression where the client's cached modification time (mtime) and change time (ctime) were not updated after a rename operation if a directory delegation was present.

Olga Kornievskaia identified the failure in xfstest generic/309, noting:

"Since commit 6f9bda2337f8 ("NFS: Fix directory delegation verifier checks") xfstest generic/309 is failing because after the rename (mv) operation, client's mtime/ctime is the same." Olga Kornievskaia

The Fix

The proposed patch corrects this by ensuring that the delegated mtime is explicitly updated during RENAME operations when directory delegations are in effect. This restores metadata consistency and allows the client to pass the relevant regression tests. The fix is narrowly scoped, touching fs/nfs/inode.c and fs/nfs/nfs4proc.c.

This Week's Activity: Review and Conclusion

The primary activity this week was the formal review of Olga's submission. Benjamin Coddington from Hammerspace examined the patch and provided his endorsement:

"Reviewed-by: Benjamin Coddington bcodding@hammerspace.com" Benjamin Coddington

Conclusion

With the review complete, this bug fix is poised for integration into the mainline kernel. It represents a critical maintenance effort in NFS client development, ensuring that performance optimizations (delegation verifier checks) do not compromise metadata correctness during common operations like file renaming.
