sunrpc sysctl: Replace deprecated simple_strtol with kstrtouint in debug interface

Summary

sunrpc: Replace Deprecated simple_strtol with kstrtouint in sysctl Debug Interface

Classification: Bug Fix / Code Hardening (NFS Client Subsystem — sunrpc)

This thread, submitted by Yufan Chen as a four-patch series titled "net: replace deprecated simple_strto parsers with kstrto*" PATCH v2 0/4, touches several networking subsystems. Only Patch 4/4 is relevant to the NFS mailing list, targeting net/sunrpc/sysctl.c — a core component of the NFS client infrastructure.

Technical Summary

The Patch (NFS-Relevant Portion)

Patch 4/4 replaces the deprecated simple_strtol() parser with kstrtouint() in the proc_dodebug() function within net/sunrpc/sysctl.c. As described by the author:

"Use kstrtouint() in proc_dodebug() after trimming trailing whitespace. This keeps accepted whitespace behavior while enforcing full-token parsing with standard errno returns." PATCH v2 4/4

The change modernizes the sysctl debug interface for sunrpc (which underpins NFS client RPC operations) by:

  1. Enforcing strict parsing: Unlike simple_strtol(), which silently accepts partial values (e.g., accepting "1abc" as "1"), kstrtouint() rejects malformed input with -EINVAL.
  2. Providing standard errno returns: Conversion failures and range errors are now reported through conventional error codes rather than relying on pointer arithmetic to detect parse boundaries.
  3. Preserving whitespace tolerance: Trailing whitespace is trimmed before parsing, maintaining backward compatibility with existing user-space tooling.

The Series Context

The broader series also addresses:

  • Patch 2/4: Parser modernization in 9p/trans_xen (not NFS-related).

"Part of the problem is that you've mixed a semi-complex 9p patch with other net patches, I think it'd be easier to move forward if you'd split this." Re: PATCH v2 0/4

Significance for NFS Client Development

While the sunrpc change itself is a relatively small refactoring, it contributes to the ongoing kernel-wide effort to eliminate deprecated string-to-integer conversion helpers. For the NFS client specifically:

  1. Hardened debug interface: The proc_dodebug() function in sunrpc handles sysctl parameters used for debugging RPC operations. Stricter parsing prevents accidental misconfiguration through malformed input.
  2. Consistency with kernel best practices: The migration from simple_strto* to kstrto* aligns the NFS client's underlying RPC layer with modern kernel coding standards.

Final Status (as of this week)

No responses were received within the reporting window. The patch series remains pending review, with subsequent out-of-window discussion indicating that splitting the series and providing more targeted testing evidence may be necessary for acceptance.
