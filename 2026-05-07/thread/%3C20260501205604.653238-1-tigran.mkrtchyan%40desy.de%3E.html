nfs-utils: Add MB/s throughput display option to nfsiostat

Summary

This week, a small but practical enhancement was merged into nfs-utils to improve the readability of performance metrics in nfsiostat.

Feature Overview

Tigran Mkrtchyan from DESY submitted a patch to allow nfsiostat to display throughput in MB/s instead of the default kB/s. He noted that modern network speeds make kilobytes-per-second figures unwieldy:

"Nowadays, the network bandwidth in kB/s is quite a large number to read. Thus, let nfsiostat display it in MB/s if requested." Tigran Mkrtchyan

The patch modified tools/nfs-iostat/nfs-iostat.py and the corresponding man page to support this new display option.

Resolution

NFS maintainer Steve Dickson reviewed and accepted the change, committing it for the upcoming nfs-utils-2.9.2 release:

"Committed... (tag: nfs-utils-2-9-2-rc2)" Steve Dickson

Significance

While not a kernel bug fix or protocol change, this utility enhancement improves the user experience for administrators monitoring high-throughput NFS mounts, aligning tooling output with contemporary bandwidth scales.
