NFSv4.1 Client Hang in nfs4_drain_slot_tbl Against Windows NFS Server

Bug Report: NFSv4.1 Client Hang Under Concurrent Workload

On May 6, 郭玲兴 reported a bug where the NFSv4.1 client hangs in nfs4_drain_slot_tbl under concurrent workload when connected to a Windows NFS server. The reporter specified the following mount options:
