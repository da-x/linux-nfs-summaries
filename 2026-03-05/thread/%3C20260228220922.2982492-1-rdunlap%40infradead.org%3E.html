SUNRPC: Fix kernel-doc warnings in xdr.h

Summary

This thread concerns a documentation cleanup patch for the SUNRPC subsystem, specifically targeting include/linux/sunrpc/xdr.h. The discussion is brief and focused on getting the patch accepted into the NFS tree.

Patch Overview

Randy Dunlap submitted a patch to eliminate kernel-doc warnings in the XDR (External Data Representation) header file. The issues were purely documentation-related:

  1. A function parameter name mismatch in xdr_set_scratch_folio (documented as @page but defined as folio).
  2. Missing return value descriptions for numerous inline functions such as xdr_stream_remaining, xdr_align_size, xdr_pad_size, and various encode/decode helpers.

"Correct a function parameter name (s/page/folio/) and add function return value sections for multiple functions to eliminate kernel-doc warnings" Randy Dunlap

Discussion and Resolution

Chuck Lever reviewed the patch positively, noting its correctness but asking about the submission route:

"Reviewed-by: Chuck Lever chuck.lever@oracle.com. Randy, did you want me to take this one, or will you send it on to Linus?" Chuck Lever

Randy Dunlap clarified that he did not have a direct route to Linus, requesting Chuck to take the patch:

"Please take it. I don't have a direct route to Linus. :)" Randy Dunlap

Chuck Lever subsequently applied the patch to the nfsd-testing tree:

"Applied to nfsd-testing, thanks!" Chuck Lever

Conclusion

This was a straightforward documentation fix (bug fix in the context of kernel-doc compliance) with no technical controversy. The patch improves the quality of the generated kernel documentation for NFS/SUNRPC developers by ensuring all function parameters and return values are properly described. It has been accepted into the nfsd-testing tree for eventual inclusion in the mainline kernel.
