NFS: Cosmetic fix converts comma to semicolon in nfs4proc.c

Summary

NFS Client: Cosmetic Fix for Comma-to-Semicolon Typo in nfs4proc

Overview

This brief thread addresses a trivial but important code quality issue in the NFS client's NFSv4 procedure handling code. The discussion centers on a patch submitted by Chen Ni to correct a syntactic typo where a comma was used instead of a semicolon between expressions in fs/nfs/nfs4proc.c.

Discussion Evolution

Patch Submission

Chen Ni submitted a one-line patch titled "[PATCH] nfs: nfs4proc: Convert comma to semicolon" on February 3, 2026. The patch replaces a comma with a semicolon between two expressions in the NFSv4 procedure code.

In the commit message, Chen Ni explained the rationale:

"Using a ',' in place of a ';' can have unintended side effects. Although that is not the case here, it is seems best to use ';' unless ',' is intended."

The patch was described as:

  • Found by manual inspection
  • Having no functional change intended
  • Compile-tested only

Review and Approval

Jeff Layton, the NFS subsystem maintainer, responded later the same day with a quick review. He concurred that this was clearly an error:

"Almost certainly a typo."

He provided his official review acknowledgment:

"Reviewed-by: Jeff Layton jlayton@kernel.org"

Technical Significance

This is classified as a bug fix, albeit a minor cosmetic one. While the comma operator in C evaluates both operands and returns the value of the rightmost operand (meaning the code likely functioned correctly in this specific instance), using a semicolon is the correct syntax when two independent statements are intended. This kind of typo can be misleading to readers and may mask actual bugs in similar contexts where the comma operator's side effects do matter.

Conclusion

The patch was swiftly reviewed and approved by the NFS maintainer. The discussion demonstrates the kernel community's attention to code clarity and correctness, even for changes that have no functional impact. This type of cleanup helps prevent future maintenance issues and improves code readability in the NFS client implementation.
