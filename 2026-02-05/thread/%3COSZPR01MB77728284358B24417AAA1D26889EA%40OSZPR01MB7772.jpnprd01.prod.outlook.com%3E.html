nfsiostat Man Page Typo Fix Committed to nfs-utils 2.8.5-rc3

Summary

Type: Bug fix (documentation / typo correction)

This thread concludes with the acceptance of a minor documentation patch for nfs-utils, specifically correcting typos in the nfsiostat man page.

Prior Week Context

Last week, Seiichi Ikarashi of Fujitsu submitted a patch as part of a larger 10-patch series ([nfs-utils PATCH 03/10]) to correct typos in the nfsiostat man page. The patch modified tools/nfs-iostat/nfsiostat.man, making two insertions and two deletions — a minimal, surgical fix targeting documentation accuracy rather than functional code changes.

This Week's Activity

NFS-utils maintainer Steve Dickson responded this week to confirm the patch was accepted:

"Committed... (tag: nfs-utils-2-8-5-rc3)"

As confirmed by Steve Dickson, the patch was merged into the nfs-utils-2.8.5 release candidate branch, indicating it is part of the ongoing preparation for an upcoming stable release of nfs-utils.

Significance

While this patch does not address core NFS client functionality or protocol-level bug fixes, clean and accurate documentation remains important for users relying on nfsiostat — a key diagnostic tool for monitoring NFS I/O statistics. The fix is part of a broader cleanup effort by Fujitsu contributors to improve the quality of nfs-utils.
