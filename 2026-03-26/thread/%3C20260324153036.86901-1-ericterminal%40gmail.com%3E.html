net: Replace deprecated simple_strto* parsers in bridge and sunrpc

Overview

This week, Yufan Chen submitted a v3 patch series focused on modernizing input parsing in two networking subsystems by replacing deprecated simple_strto* functions with their safer kstrto* counterparts. The series is classified as a bug fix / code hardening effort, aimed at improving error reporting consistency and tightening parse semantics in sysfs and procfs interfaces.

The series was split from a previous mixed 9p/net submission to align with subsystem boundaries and ease review, as noted by the author:

"This series replaces deprecated simple_strto* parsers in two net paths with kstrto* helpers and tightens parse semantics." Eric-Terminal

Patch Details

Patch 1: net: bridge – replace deprecated simple_strtoul with kstrtoul

In brport_store(), the patch switches from simple_strtoul() to kstrtoul() to ensure that parse failures and range errors return standard errno values before acquiring the bridge lock. This change removes a deprecated API and improves error handling robustness.

"switch to kstrtoul() so parse failures and range errors return standard errno directly before taking the bridge lock." Eric-Terminal

Patch 2: net: sunrpc – replace deprecated simple_strtol with kstrtouint

This patch updates proc_dodebug() in the SunRPC subsystem to use kstrtouint() for full-token conversion. It preserves acceptance of surrounding whitespace while rejecting malformed input, thereby avoiding partially parsed values in control paths.

"trim trailing whitespace and use kstrtouint() for full-token conversion, preserving acceptance of surrounding whitespace while rejecting malformed input." Eric-Terminal

The author emphasized the benefit for NFS-related sysctl paths:

"This replaces the deprecated simple_strtol(), improves error reporting consistency, and avoids partially parsed values in control paths." Eric-Terminal

Testing and Validation

The author reported that the migration ensures sysfs/procfs interfaces now properly validate the entire input string:

"Verified migration to kstrto* ensures that sysfs/procfs interfaces now properly validate the entire input string, rejecting malformed input." Eric-Terminal

Discussion Evolution and Status

This is v3 of the series. The author noted:

"No functional changes since v2." Eric-Terminal

The primary change from earlier versions was the structural split into a dedicated net series for bridge and sunrpc, rather than mixing with 9p changes. No replies or further discussion were observed within this week's window; the patches appear to be awaiting review by subsystem maintainers.

Relevance to NFS Client Development

While the bridge patch is unrelated to NFS, the sunrpc patch directly impacts the NFS client infrastructure. The net/sunrpc/sysctl.c file contains debug and control interfaces used in NFS/RPC troubleshooting. By replacing simple_strtol() with kstrtouint(), the patch ensures that malformed inputs to these sysctl knobs are rejected cleanly, reducing the risk of undefined behavior or partially applied configurations in production NFS deployments. This is a defensive improvement that enhances the reliability of NFS client debugging and administration interfaces.
