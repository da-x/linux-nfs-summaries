pynfs ACL-on-Creation Tests: Status Update from Calum Mackay

Summary

This week, a single message was posted in this long-running thread concerning test coverage for an NFSv4 bug fix. Calum Mackay responded to Aurélien Couderc's inquiry (from the prior week) regarding the status of pynfs regression tests for the ACL-on-file-creation defect originally fixed by Chuck Lever in November 2025.

Background (Prior Weeks)

The thread originated with Chuck Lever's patch submission in November 2025, which fixed a bug where the NFSv4 server neglected to set POSIX ACLs during file creation. As Chuck explained at the time:

"An NFSv4 client that sets an ACL with a named principal during file creation retrieves the ACL afterwards, and finds that it is only a default ACL (based on the mode bits) and not the ACL that was requested during file creation. This violates RFC 8881 section 6.4.1.3: 'the ACL attribute is set as given'."

Chuck had mentioned developing new pynfs tests while troubleshooting the issue, but his upstream repository had not seen updates for months. Last week, Aurélien Couderc followed up, noting:

"https://git.linux-nfs.org/?p=cdmackay/pynfs.git;a=summary was not updated since 10 months. Are the patches stuck, or something else happened"

This Week's Activity

On March 11, Calum Mackay replied directly to Aurélien's inquiry, providing a brief but reassuring status update:

"Apologies; I have a number of patches queued up that I need to push out. Will do that asap."

This response confirms that the pynfs test patches are not lost or abandoned — they exist and are pending submission. The delay appears to be due to other priorities rather than technical blockers.

Classification

  • Type: Bug fix validation (test infrastructure)
  • Component: NFSD (NFSv4 server), pynfs test suite
  • Status: Pending — patches queued for imminent submission by Calum Mackay

Conclusion

This week's message closes the loop on an open question raised last week. The kernel-side fix for the ACL-on-creation bug has been in place since November 2025, and corresponding pynfs regression tests are now confirmed to be in preparation. Calum Mackay's assurance that patches will be pushed "asap" suggests that test coverage for this defect should arrive in the near future, helping to prevent regressions in this area of NFSD functionality.
