nfsdclnts: Missing-superblock crash fix committed to nfs-utils

Summary

This thread, originally opened last week by Frank Sorenson's patch submission, reached closure this week with Steve Dickson confirming the fix has been merged into nfs-utils.

Prior Context (Week of 2026-03-05)

Last week, Frank Sorenson submitted a bug fix for nfsdclnts, the userspace tool used to inspect NFS server client state. The patch addressed a crash that occurred when the kernel could not locate the file associated with a stateid and consequently omitted superblock information from the /proc/fs/nfsd/clients/<client>/states procfile. As Sorenson explained:

"If the stateid's file can't be found, the kernel will skip printing the superblock and filename in the 'states' procfile. When this happens, nfsdclnts crashes trying to reference the non-existent superblock key while getting the inode."

The fix set the inode field to 'N/A' when the superblock was absent, consistent with how other optional fields were already handled in the tool.

This Week's Activity (Week of 2026-03-12)

This week saw a single follow-up message from Steve Dickson confirming the patch had been accepted and merged:

"Committed... (tag: nfs-utils-2-8-6-rc4)" — Steve Dickson

The fix is now included in the nfs-utils-2.8.6-rc4 release candidate tag.

Classification

  • Type: Bug fix
  • Component: NFS server userspace tools (nfsdclnts, part of nfs-utils)
  • Status: Committed (tag: nfs-utils-2-8-6-rc4)
  • Impact: Prevents a crash in nfsdclnts when inspecting client state on systems where some stateids reference files the kernel cannot resolve (e.g., deleted or inaccessible files).

Conclusion

This is a minimal, well-scoped bug fix that improves the robustness of nfsdclnts as a diagnostic tool. The patch touches a single file (tools/nfsdclnts/nfsdclnts.py) and ensures administrators can inspect NFS client state without encountering crashes due to edge-case kernel behavior where superblock data is unavailable. With Steve Dickson's confirmation, the fix has been merged and will ship in the upcoming nfs-utils 2.8.6 release.
