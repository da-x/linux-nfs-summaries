NFS Client Bugfixes for Linux 7.0-rc: KConfig, RDMA, and NFSv3 Fixes

Summary

NFS Client Bugfixes Merged for Linux 7.0-rc2

Anna Schumaker submitted a small but critical pull request containing three bug fixes for the NFS client subsystem, targeting the Linux 7.0-rc cycle. The changes address configuration typos, a reference counting issue in the RDMA transport layer, and an incorrect error return in the NFSv3 create procedure.

Bug Fixes Overview

The pull request, tagged as nfs-for-7.0-2, was accepted and merged into Linus Torvalds's tree on March 12, 2026. As confirmed by the PR tracker bot, the merge was completed without objection.

The three fixes included are:

1. NFS KConfig Typos

Anna Schumaker corrected typographical errors in the NFS kernel configuration files (fs/nfs/Kconfig). While seemingly minor, accurate Kconfig entries are essential for proper build-time configuration and user understanding of available options.

2. RDMA Transport Reference Count Fix

Eric Badger contributed a fix to the xprtrdma subsystem, specifically addressing an issue where the re_receiving counter was not decremented on early exit paths in net/sunrpc/xprtrdma/verbs.c. This is a significant stability fix for NFS over RDMA deployments:

"Decrement re_receiving on the early exit paths"

Failure to properly decrement this counter could lead to resource leaks or incorrect state tracking in the RDMA transport layer, potentially affecting performance and reliability of high-speed NFS mounts.

3. NFSv3 Create Error Handling

Roberto Bergantinos Corpas fixed an issue in fs/nfs/nfs3proc.c where nfs3_proc_create would not correctly return EISDIR when the target directory alias (d_alias) was itself a directory:

"return EISDIR on nfs3_proc_create if d_alias is a dir"

This ensures that attempts to create a file within a path component that is a directory (rather than a regular file) are properly rejected with the standard POSIX error code, maintaining correct semantics for NFSv3 clients.

Conclusion

This pull request represents typical end-of-rc-cycle maintenance: small, targeted fixes addressing correctness and stability issues in the NFS client stack. The inclusion of an RDMA transport fix highlights the ongoing importance of optimizing NFS for high-performance storage environments, while the NFSv3 create fix ensures proper POSIX compliance. All three patches were merged cleanly into the mainline kernel.
