Technical Context

Based on the subject line alone, this bug concerns:

  • nfs_free_request: The NFS client function responsible for cleaning up and freeing page read/write requests after completion
  • PG_WB_END: A page flag indicating the end of a writeback range — typically used to track which pages are involved in I/O operations
  • FS-Cache interaction: The Linux FS-Cache subsystem provides filesystem-level caching, and NFS can use it for client-side caching. The warning suggests that during NFS read completion, a page marked with PG_WB_END is found in an unexpected "stale" state

This type of warning typically indicates a race condition or incorrect flag management between the NFS client's page cache operations and FS-Cache's writeback tracking mechanisms.
