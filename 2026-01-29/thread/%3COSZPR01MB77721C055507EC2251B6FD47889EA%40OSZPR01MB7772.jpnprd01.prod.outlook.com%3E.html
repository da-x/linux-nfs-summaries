statd: Typo Fix in Debug Message (PATCH 10/10)

Overview

This thread covers the final patch in a 10-patch series submitted by Seiichi Ikarashi of Fujitsu, targeting typo corrections across the nfs-utils user-space tools suite. This specific submission — [PATCH 10/10] statd: fix a typo in a debug message OSZPR01MB77721C055507EC2251B6FD47889EA@OSZPR01MB7772.jpnprd01.prod.outlook.com — is a bug fix (editorial correction in source code), not a new feature or protocol change.

Patch Details

On January 29, 2026, Seiichi Ikarashi submitted the patch, which modifies utils/statd/simulate.c with a one-line correction (1 insertion, 1 deletion). The patch corrects a typographical error in a debug message within the NFS status monitor daemon (statd) simulation code.

The patch carries only a Signed-off-by line:

"Signed-off-by: Seiichi Ikarashi s.ikarashi@fujitsu.com"

Series Context

This is the tenth and final patch in a cohesive series of typo fixes across nfs-utils. The preceding nine patches (01/10 through 09/10) corrected typos in man pages for nfs.conf, mountstats, nfsiostat, rpcctl, exports, gssd, nfs, mountd, and nfsd. Patch 10/10 is notable as the only patch in the series that targets a runtime debug message string in C source code (simulate.c) rather than documentation files.
