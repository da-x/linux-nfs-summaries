nfsiostat man page typo fixes merged into nfs-utils 2.8.5-rc3

Summary

nfsiostat Man Page Typo Corrections

Type: Bug fix (documentation / typo correction)

This brief thread covers a minor but welcome documentation improvement to the nfs-utils project, specifically targeting the nfsiostat man page.

Overview

Seiichi Ikarashi of Fujitsu submitted a patch as part of a larger 10-patch series ([nfs-utils PATCH 03/10]) to correct typos in the nfsiostat man page. The patch modifies tools/nfs-iostat/nfsiostat.man, making two insertions and two deletions — a minimal, surgical fix targeting documentation accuracy rather than functional code changes.

Discussion and Resolution

The thread was short-lived, with nfs-utils maintainer Steve Dickson responding off-week (February 1st) to confirm acceptance:

"Committed... (tag: nfs-utils-2-8-5-rc3)"

As noted by Steve Dickson, the patch was merged into the nfs-utils-2.8.5 release candidate branch, indicating it is part of the ongoing preparation for an upcoming stable release of nfs-utils.

Significance

While this patch does not address core NFS client functionality or protocol-level bug fixes, clean and accurate documentation remains important for users relying on nfsiostat — a key diagnostic tool for monitoring NFS I/O statistics. The fix is part of a broader cleanup effort by Fujitsu contributors to improve the quality of nfs-utils.
