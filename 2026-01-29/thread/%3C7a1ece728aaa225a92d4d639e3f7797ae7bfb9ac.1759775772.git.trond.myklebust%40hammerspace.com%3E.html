libtirpc: Missing rpc_gss_getcred and authdes_getucred Exports Committed

Summary

Missing libtirpc Symbol Exports Committed After Months of Delay

Overview

This thread concerns a straightforward bug fix in the libtirpc library, which underpins NFS client authentication mechanisms including RPCSEC_GSS and DES-based credentials. The patch adds missing symbol exports for two functions that were documented in the official API but absent from the shared library's export map.

The Problem

Trond Myklebust submitted a patch on October 6, 2025, addressing an inconsistency between the documented libtirpc API and its actual exported symbols. As he explained:

"Both functions are listed as part of the official API in the libtirpc manpages. However they are not listed as being exported, and therefore do not turn up in the shared library." Original patch

The two affected functions are:

  • rpc_gss_getcred — used for obtaining RPCSEC_GSS credentials, critical for Kerberos-based NFS authentication.
  • authdes_getucred — used for DES-based credential retrieval.

Both are part of the NFS client's authentication infrastructure. The absence of these exports from libtirpc.map would cause link-time failures or runtime symbol resolution errors for any application (including NFS utilities) relying on these documented functions.

Resolution

Steve Dickson, the maintainer of libtirpc, confirmed the patch was committed in a reply dated January 23, 2026:

"Committed.... sorry it took so long." Commit confirmation

The nearly three-month delay between submission and commit is notable, though no technical objections were raised — the fix was accepted as-is.

Significance for NFS Client Development

This bug fix ensures that applications depending on libtirpc can properly link against its documented credential-handling API. For NFS clients using Kerberos (RPCSEC_GSS) or DES authentication, these exports are essential. Without them, builds of NFS utilities or custom client applications may fail when attempting to use these standard functions, even though they are officially supported and documented.

The patch modifies two files (src/libtirpc.map and src/libtirpc.map.in), adding the missing symbol entries to ensure the shared library correctly exports both functions.

Classification

Bug fix — correcting an omission in the library's export map that prevented documented API functions from being accessible at link time.
